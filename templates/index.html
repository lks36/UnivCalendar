Recevoir les changements dans l'app Calendrier

Abonnez-vous une fois : votre iPhone / Mac se met à jour tout seul quand un cours est déplacé ou annulé.

S'abonner (Apple Calendrier)
Comment faire ?
  • Mac (recommandé) : Calendrier → Fichier → Nouvel abonnement à un calendrier → collez le lien → Emplacement : iCloud, Actualisation automatique : toutes les heures. Il apparaîtra aussi sur votre iPhone.
  • iPhone seul : touchez « S'abonner » ci-dessus, ou Réglages → Calendrier → Comptes → Ajouter un compte → Autre → Ajouter un calendrier avec abonnement.
  • Google Agenda : sur ordinateur, Autres agendas → + → À partir de l'URL → collez le lien.
  • Si vous aviez importé le fichier .ics avant, supprimez l'ancien calendrier pour éviter les doublons : un fichier importé ne se met jamais à jour.
